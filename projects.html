category graphics/simulation
An experimental terrain generation program that simulates hydraulic erosion. Uses different types of 2D-noise to generate an initial heightmap and then transforms the terrain via a large number of simulated water droplets, each of which transfers a small amount of "sediment" as it moves along the terrain.
legs-and-gaits
created ...
updated ...
built in godot
category procedural animation
Proof-of-concept for a novel procedural animation technique for quadruped locomotion. Introduces a parametric leg structure that can model plantigrade, digitigrade, and ungiligrade legs. Uses analytic IK for bone transformations (instead of the usual numerical IK techniques used in procedural animation) and coordinates foot movement with special parametric wave functions.
